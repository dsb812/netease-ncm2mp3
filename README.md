# netease-ncm2mp3

把**你自己在网易云音乐客户端下载的** `.ncm` 文件转换成标准 MP3（或还原成无损 FLAC）的小工具，带图形界面，支持批量与并行转换。

> 本工具只做「本地文件格式转换」，不包含任何绕过付费、会员或版权限制的功能。请仅用于转换你合法获取的音乐。

## 功能

- 拖入 `.ncm` / `.flac` / `.mp3` / `.m4a` 等文件，或直接选一整个文件夹（递归扫描）
- 批量并行转换（默认按 CPU 核心数，可手动调）
- 输出 MP3 128 / 192 / 320 kbps，或保留无损
- 自动把歌名、歌手、专辑写入 ID3 标签
- 文件名支持「歌手 - 歌名」「歌名 - 歌手」「沿用原文件名」三种规则
- 跳过已存在的文件，重复运行不会重复干活
- 实时进度、逐条日志、失败原因可见

## 原理（简述）

`.ncm` 是在原始音频外面加了一层封装：

```
magic "CTENFDAM" | 2B | 密钥块(AES-128-ECB, XOR 0x64) | 元数据(AES-128-ECB + Base64)
                 | CRC | 5B | 封面长度+数据 | 音频数据(RC4 类流加密)
```

解密后拿到的是**完整的 FLAC 或 MP3 原文件**（带文件头），因此可以无损还原，再按需转码。
关键点有两个，踩过才知道：

1. 解出的密钥数据要先去掉 `neteasecloudmusic` 前缀、并做 PKCS#7 去填充，否则密钥盒是错的；
2. 逐字节 XOR 在 Python 里极慢，而密钥流周期固定为 32 KB，可以按块用大整数异或，50 MB 的歌从 40 秒降到 0.3 秒。

## 使用

### 直接运行源码

```bash
pip install -r requirements.txt
python app.py
```

需要一个 `ffmpeg`：把 `ffmpeg.exe` 放到程序目录（或 `bin/` 子目录），或者装到系统 PATH 里。

### 打包成 exe

```bash
pip install pyinstaller
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物在 `dist/netease-ncm2mp3.exe`，把 `ffmpeg.exe` 放到 exe 同目录即可使用。

## 常见问题

**Q: 提示「不是有效的 .ncm 文件」？**
不是 ncm，或者文件下载没完成（0 字节 / 半截）。重新下载一次试试。

**Q: 解密出来是噪声 / 转码失败？**
说明这个文件用了新的密钥格式。请提 issue 并附上文件头前 64 字节的十六进制。

**Q: 转出来没有封面？**
转 MP3 时默认不嵌封面（点读笔、车载音响多数不读）。需要的话可以自行加 `-map 0:v` 参数。

**Q: 支持 macOS / Linux 吗？**
核心逻辑跨平台，把 `find_ffmpeg()` 指到系统 ffmpeg 即可；界面用的 tkinter，三平台都能跑。
